# 主页图片与附件

请在 `academic-homepage-draft` 草稿分支的此文件夹上传个人资料文件。

建议文件名：
- `avatar.jpg`：个人头像。
- `cv.pdf`：公开版个人简历。
- `paper-1.png`：论文方法或结果示意图。

在本目录点击 **Add file → Upload files**，上传后提交到草稿分支。然后按根目录 `PROFILE-TEMPLATE.md` 的说明修改 `index.html` 中的相对路径。

当前未包含任何真实个人照片或简历；请不要提交不愿公开的资料。公开仓库里的草稿分支也公开可见。

不要将草稿合并到 main，除非已决定发布。
